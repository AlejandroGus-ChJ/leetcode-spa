# Explore Page

The `ExplorePage` component allows users to browse and filter coding interview topics by category and difficulty level. It features interactive metrics cards, live filtering mechanisms, and visual progress tracking.

## Criterias Included

- Full responsive layouts (from mobile viewpoints up to large desktops).
- Mapped difficulty tag indicators (`success`, `warning`, `error`).
- Skeleton loaders for pending asynchronous states.
