# Explore Page

This page allows users to browse different learning topics, filter them by category or difficulty, and track their progress.

### Components used:
- **Material UI Grid**: For the responsive layout.
- **Material UI Card**: To display each topic.
- **LinearProgress**: To show the learning advancement.

### How to use:
1. Navigate to the Explore section.
2. Filter topics using the category buttons.
3. Click "Continue" to resume your progress.
